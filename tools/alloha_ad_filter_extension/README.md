# CineVault · без рекламы в плеерах

Расширение для Chrome, Edge, Arc и других браузеров на Chromium.

- **Alloha**: подменяет ответ `POST https://pc.alloviewroll.com/lists.php` на пустой
  список рекламы в окнах плеера на `*.stravers.live` (`filter.js`).
- **Все плееры**: блокирует запросы к известным рекламным сетям (`rules.json`) —
  Яндекс и AdFox, Google, myTarget, российские видеосети и адреса рекламы Collaps
  (`distribrey.com`, `hg-delivery.b-cdn.net`). Тот же список встроен в iOS-приложение
  (`ios/CineVault/EmbedPlayers.swift`, `PlayerAdBlocker`).

Видео, его серверы, токены и cookies расширение не трогает, ничего не сохраняет и
никуда не отправляет. Рекламу, вшитую в само видео, убрать так нельзя, а провайдеры
могут сменить адреса — тогда список нужно дополнить.

## Установка

1. Распаковать архив в папку.
2. Открыть `chrome://extensions` (или `edge://extensions`), включить «Режим разработчика».
3. «Загрузить распакованное» → выбрать эту папку.
4. Перезагрузить страницу с фильмом.

Если плеер перестал работать — выключить расширение на той же странице и перезагрузить.
