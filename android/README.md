# CineVault Android

Нативный клиент на Kotlin и Jetpack Compose. Он использует серверный каталог CineVault, воспроизводит прямые HLS-ссылки через Media3 и открывает Alloha во встроенном WebView.

## Сборка

Нужны Android SDK Platform 37, Android Build Tools 37 и JDK 17. Открой папку `android` в Android Studio либо собери APK командой:

```sh
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. `local.properties` содержит путь к SDK и не попадает в Git.

Gradle читает Basic Auth из `../ios/Secrets.xcconfig`, если файл есть на этой машине. Значения встраиваются в APK, поэтому debug APK следует оставлять для личного использования и передавать только доверенным людям. Исходные значения в репозиторий не копируются.

## Что уже подключено

- серверные поиск, фильтры, сортировки и пагинация каталога;
- отдельная лента «Для вас» с популярным, новым и жанровыми подборками;
- карточка фильма или сериала, актуализация видеоссылок и список озвучек Alloha;
- полноэкранный Media3 Player с управлением для прямых HLS/видео ссылок;
- Alloha во вложенном WebView с тем же узким рекламным фильтром, который используется браузерным расширением и iOS;
- загрузка выбранного качества HLS для серий, хранящихся в медиатеке CineVault, и локальное офлайн-воспроизведение.

## Android TV

В APK есть отдельная Android TV-активность (`TvActivity`) с широкоформатной главной и каталогом, пультовой навигацией, карточками, онлайн-плеером CineVault и Alloha. Она запускается через TV launcher; мобильная версия остаётся обычной точкой входа. Загрузка видео на ТВ не предлагается: просмотр только через интернет.

Для проверки создай в Device Manager виртуальное устройство профиля Android TV, запусти его и установи тот же `app-debug.apk`. Затем открой CineVault на главном экране эмулятора ТВ.

Фильтр подключается к WebView только для origin `https://theatre.stravers.live`; сам скрипт берётся из `../tools/alloha_ad_filter_extension/filter.js`.

Офлайн-загрузка работает только для собственных файлов медиатеки CineVault, доступных через `/api/library/.../offline-manifest`. Внешние iframe-плееры, включая Alloha, не отдают приложению поток для сохранения; приложение их не скачивает.
