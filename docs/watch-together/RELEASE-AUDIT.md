# Проверка выпуска iframe Alloha — 02.11.2026

## Принятый объём

Перечитан `docs/prompts/alloha-watch-together-v2.md`, включая разделы аккаунтов и приёмки. Последняя поправка пользователя — оставить iframe с ограничениями; `/direct` не подключать. Последнее указание разрешает деплой после проверки.

Не объявляем выполненными исходные требования, невозможные в принятой интеграции: строгий запрет pause/seek внутри iframe у зрителя, достоверный буфер/canplay, автоматическое ожидание всех и гарантированное восстановление после любого переключения качества. В интерфейсе это объяснено. Для зрителя есть явный возврат к ведущему, без борьбы с ручными действиями.

## Проверки и границы

- Локально: 151 Python-тест, 18 JS-тестов (комната, аккаунтный клиент, главная); синтаксис и diff-check.
- В образе Python 3.12: 151 Python-тест. Для тестов смонтированы локальные demo-фикстуры и неиспользуемый адаптер /direct; они не добавлены в рабочий образ.
- Реальный браузер: два аккаунта через 127.0.0.1/localhost, настоящий фильм, общая история → новая комната → один → раздельная история. Реальное восстановление роли ведущего.
- Длительный прогон: см. `iframe-release-long-run.json`. Это серверные отчёты двух реальных iframe в одном браузере/сети, а не сравнение кадров на физических устройствах. Финальный защитный обработчик отличающейся длительности добавлен после старта этого прогона и проверен модельным тестом; сам длинный прогон не доказывает его работу на реальных разных версиях фильма.
- Всё ещё требуется ручная проверка физического телефона/Safari, двух сетей/VPN, 1080p, серий и озвучек на реальном контенте. Она не подменяется количеством unit-тестов и не помечена выполненной.

## Релиз и откат

Изменяются только явно перечисленные файлы сайта и backend. Живые `app/data/`, `.env`, compose/Caddy, iOS и Android не заменяются. Исходники сверены с текущим сервером; пересекающиеся изменения — прежняя версия комнат. Код и SQLite: `/srv/cinevault/deploy-backups/20261102-iframe-v3/`.

Новый образ `cinevault-iframe:20261102-v3`, откат `cinevault-rollback:iframe-20261102-v3`. Скрипт переключения `/tmp/cv-switch-release.py` проверяет контрольные суммы старого кода до записи. Откат: `python3 /tmp/cv-switch-release.py --rollback`; возвращает файлы и прежний образ, не удаляет новые данные SQLite. Повод для отката: health не поднимается, авторизованный сайт/аккаунты/комнаты дают 5xx, теряется прежний каталог, либо не проходит проверка полномочий зрителя.

После переключения: HTTPS с Basic Auth, Secure/HttpOnly cookie, регистрация двух тестовых аккаунтов, создание/join/seek/end комнаты, отказ зрителю в команде, отсутствие секретов в GET, удаление созданных тестовых аккаунтов. Результат выкладки дописывается ниже только после фактической проверки.
