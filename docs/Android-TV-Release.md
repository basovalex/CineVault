# Выпуск Android TV приложения

Как новая версия попадает на телевизоры, свои и друзей.

## Как это устроено

- Сервер раздаёт последнюю версию из `<data-dir>/apk/`: `CineVault-android.apk` и `android.json` (версия, sha256, «что нового»). Код раздачи — `tools/app_updates.py`.
- Приложение при запуске (и не чаще раза в 30 минут) спрашивает `/tv/latest.json`. Если там versionCode больше своего, на главной появляется «Доступна новая версия → Обновить». APK скачивается, сверяется по sha256 и отдаётся системному установщику.
- `/tv` — страница со скачиванием и инструкцией (за паролем сайта).
- `/dl/<токен>` — та же APK без пароля, для Downloader на телевизоре друга. Токен задаётся в `CINEVAULT_APK_TOKEN` (16+ символов) на сервере. В Caddy для `/dl/*` есть отдельный `handle` без пароля и без куки сайта. Сменить токен — значит отключить старую ссылку.

## Выпустить новую версию

С Мака, из корня репозитория:

```bash
CINEVAULT_DEPLOY_SSH=root@<сервер> tools/release_android.sh "Что нового — одной строкой"
```

Скрипт:
1. поднимает версию в `android/app/build.gradle.kts` (0.4.2 → 0.4.3, versionCode +1); с `--no-bump` оставляет как есть;
2. собирает release APK (JDK 17) и кладёт копию в `output/CineVault-android.apk`;
3. выкладывает APK, потом `android.json` (телевизор не увидит версию раньше файла);
4. печатает ответ `/tv/latest.json` с сервера.

Пересобирать контейнер не нужно. Изменение версии в `build.gradle.kts` после выпуска закоммитить.

## Первая установка у друга

Инструкция для отправки — `output/Как установить CineVault на телевизор.txt` (не в Git: в ней секретная ссылка). Короче всего через Downloader: друг набирает ссылку `/dl/<токен>` пультом. Дальше обновления приходят сами.

Важно: в APK вшит логин и пароль Basic Auth сервера, поэтому ссылку `/dl/…` не публикуют.
