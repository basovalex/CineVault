# Аудит Lampa → CineVault (12.11.2026)

Источник: исходники `yumata/lampa-source` (`src/core/api/sources/tmdb.js`, `src/components/*`, `src/interaction/*`) и живой Lampac на сервере.

## Главный вывод

У Lampa **нет своего каталога**. Главная, разделы, подборки, жанры, персоны, «похожие» — живые запросы к TMDB. Лента — готовый API CUB (`cub.red/api/feed/all`). У CineVault наоборот: свой каталог из JSON-файлов, SQLite-индекс и ~10 ночных синхронизаций (Кинопоиск, Alloha, Wikidata).

Проверено с сервера (Нидерланды): TMDB доступен через прокси Lampac (`/tmdb/api/3/...` → 200), картинки `image.tmdb.org` → 200, лента `cub.red/api/feed/all` → отдаёт записи. Значит, всё можно брать так же, как Lampa.

## Как Lampa строит подборки (из `tmdb.js`)

| Лента | Запрос TMDB |
|---|---|
| Сейчас смотрят | `discover/movie` с `with_release_type=4|5|6` за последние 90 дней — только фильмы с **цифровым/физическим/ТВ-релизом**, то есть не экранки |
| Тренды дня / недели | `trending/movie/day`, `trending/movie/week` |
| Скоро | `movie/upcoming` |
| Популярные фильмы / сериалы | `movie/popular`, `trending/tv/week` |
| Топ фильмов / сериалов | `movie/top_rated`, `tv/top_rated` |
| Дальше бесконечно | по жанру: `discover/movie?with_genres=<id>` — догружается при прокрутке |
| Разделы (фильмы/сериалы/мультфильмы) | «Сейчас смотрят», «Популярное», «Последний год» (`primary_release_year=год-1`), «Стоит пересмотреть» (диапазон дат), «Высокий рейтинг» (`vote_average 8–9`), «На этой неделе», жанры; мультфильмы = жанр 16 |
| Персона | `person/<id>` + фильмография, сортировка по оценке и голосам |
| Карточка | `movie|tv/<id>?append_to_response=content_ratings,release_dates,external_ids,keywords,images` |
| Лента | `cub.red/api/feed/all`: записи `new` / `episode` / `trailer` / в высоком качестве, с кадром серии (`still_path`) |
| Цвет интерфейса | `utils/color.js` + `interaction/background.js`: доминирующий цвет постера → фон |
| Прогресс | `interaction/timeline.js`: таймкод по хэшу «карточка + сезон + серия» |

## Порядок работ

1. **Просмотр** — запоминание по тайтлу, лишние сезоны, следующая серия с кадром, порядок «озвучка → сезон → серии».
2. **Каталог** — главная и разделы на TMDB как в таблице выше, бесконечная прокрутка, персоны, «не экранка». Свой каталог и ночные синхронизации после этого можно выключить.
3. **Лента и подписки** — лента из CUB, подписка на сериал с проверкой новых серий на сервере.
4. **Дизайн** — цвет от постера, анимации, новый внешний вид (согласовать с Сашей).
5. **Уборка** — удалить старые плееры с сайта, перевести iOS, удалить их серверную часть.
